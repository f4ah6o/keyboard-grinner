
# 全体方針まとめ

## 1. 目的
複数の矩形（キー）を横に並べ、行ごとに  
* **水平（回転なし）**
* **下円回転**
* **上円回転**

の 3 種類の行区分を持たせつつ、円を基準に各矩形を回転させる。  
その結果生じる **行間の隙間（ギャップ）を最小化**する。

---

## 2. ユーザー入力とデータ構造

### ユーザーが指定するもの
* 行数  
* 各行の矩形数  
* 幅広キーの幅（0.25 単位で 1〜5 程度）
  - 最下段は任意位置
  - 最上段・中段は左右端のみ幅広可

### RowSpec（行データ構造）
* `key_widths`: 行の左から並ぶキー幅（全行で幅合計が同じ）
* `segment_lengths`:  
  `水平左 / 下円 / 上円 / 下円 / 水平右` の矩形数  
  → `[hL, b1, t, b2, hR]` の 5 要素  
* 合計が key_widths の長さと一致すること

---

## 3. 円（pivot）配置ルール

3つの中心座標：
* 上円の中心 x 座標 ×1
* 下円の中心 x 座標 ×2（左右）

### 配置方針
* 総幅 W のとき、中心 x 座標は固定：
  * 上円の x = **W/2**
  * 下円の x = **W/4**, **3W/4**
* y 座標と半径は **各行ごとに異なる値** を持つ：
  * 各行について、担当する矩形の位置に基づいて y 座標を計算
  * 各行について、担当する矩形の「ピボット→円中心」距離から半径を計算

### 円の半径
各行ごとに、その行の担当矩形の「ピボット→円中心」の平均距離を使う。
