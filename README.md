
# 全体方針まとめ

## 1. 目的
複数の矩形（キー）を横に並べ、行ごとに  
* **水平（回転なし）**
* **下円回転**
* **上円回転**

の 3 種類の行区分を持たせつつ、円を基準に各矩形を回転させる。  
その結果生じる **行間の隙間（ギャップ）を最小化**する。

---

## 2. ユーザー入力とデータ構造

### ユーザーが指定するもの
* 行数  
* 各行の矩形数  
* 幅広キーの幅（0.25 単位で 1〜5 程度）
  - 最下段は任意位置
  - 最上段・中段は左右端のみ幅広可

### RowSpec（行データ構造）
* `key_widths`: 行の左から並ぶキー幅（全行で幅合計が同じ）
* `segment_lengths`:  
  `水平左 / 下円 / 上円 / 下円 / 水平右` の矩形数  
  → `[hL, b1, t, b2, hR]` の 5 要素  
* 合計が key_widths の長さと一致すること

---

## 3. 円（pivot）配置ルール

円は 3 個：
* 上円 ×1  
* 下円 ×2（左右）

### 配置方針
* 総幅 W のとき  
  * 上円の x = **W/2**  
  * 下円の x = **W/4**, **3W/4**
* y は  
  * 上円：最上段より少し上  
  * 下円：最下段より少し下  
  （上下の回転による沈み込みが相殺される前提）

### 円の半径
描画用に、担当矩形の「ピボット→円中心」の平均距離を使う。
